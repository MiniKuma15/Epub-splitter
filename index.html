Epub Toolkit สำหรับ Xteink by Mimee Reader

เครื่องมือรวม 3 อย่างสำหรับแก้ไข epub ที่ export จาก Google Docs — ทำงานทั้งหมดในเบราว์เซอร์ ไม่มีการอัปโหลดไฟล์ไปเซิร์ฟเวอร์ใด ๆ

แก้ปัญหา status bar ไม่ขึ้นชื่อ chapter เพราะทุกบทถูกรวมในไฟล์เดียว
Google Docs มักใส่ตัวหนา/เอียง/ขีดเส้นใต้/ขีดฆ่า/ตัวยก-ตัวห้อย/จัดกึ่งกลาง-ซ้าย-ขวา/ย่อหน้า/ระยะห่างก่อน-หลังย่อหน้า/ระยะห่างระหว่างบรรทัด ผ่าน CSS class ซึ่งรีดเดอร์บางตัวอ่านไม่ได้ เครื่องมือนี้แปลงกลับเป็นแท็ก/attribute/inline style ตรง ๆ ให้ทั้งหมด
อัปโหลดรูปปกใหม่ (jpg/png) จะเข้าไปแทนที่ปกเดิมใน epub
epub จาก Google Docs มักไม่มีหน้าปกจริงในเล่ม มีแค่รูปสำหรับ thumbnail เท่านั้น ทำให้เปิดอ่านแล้วไม่เห็นปก ตัวเลือกนี้จะสร้างหน้าปกจริงให้ (ข้ามถ้าเจอว่ามีอยู่แล้ว)
ค่าปัจจุบันของไฟล์จะขึ้นให้อัตโนมัติเมื่อเลือกไฟล์ แก้ตรงไหนก็เปลี่ยนตรงนั้น เว้นว่างไว้ = ไม่เปลี่ยน

หมายเหตุ: การแยกบทจะแยกเฉพาะไฟล์เนื้อหาที่มี Heading 1 ตั้งแต่ 2 อันขึ้นไป ไฟล์ที่มีไม่ถึงจะถูกปล่อยไว้เหมือนเดิม (แต่ยังแก้ตัวหนา/เอียงได้ตามปกติ)
